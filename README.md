The attached functions and scripts serve to identify behaviorally-relevant states in timeseries data using MATLAB.

discretesimulation.m generates simplified discrete timeseries with covariate-dependent activity.

fMRIsimulation.m generates simulated fMRI timeseries with covariate-dependent activity.

gastates.m serves to identify behaviorally-relevant states using a genetic algorithm.

examplescript.m provides an example workflow using the prior functions.
